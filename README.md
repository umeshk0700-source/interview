# Perfect Candidate

A practice and preparation site for interviews and exams. Paste a job description once, then:

- **Interview**: ask by voice, read the answer as it streams. It ignores your own speech.
- **Exam help**: typed or photographed questions get the answer first, then the working.
- **Mock interview**: questions built from the JD, a score per answer, a stronger version, and a final scorecard.
- **Prep kit**: pitch, cover letter, resume bullets, questions to ask, 30-60-90 plan, negotiation script.
- **Candidate profile**: a pitch, strengths, stories and likely questions that every answer stays consistent with.

The whole app is `perfect-candidate.html`, published as a Claude artifact. It uses the artifact `sample` (ask Claude) and `dictation` (voice) capabilities, so it needs no server or API key. Role details are kept in the browser's local storage.

Use it to practise. Check answers against real material before relying on them.
